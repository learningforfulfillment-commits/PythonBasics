# Fraud Detection Using Machine Learning

This project builds an end-to-end fraud detection system using a real-world
mobile money transaction dataset containing over 6 million records.

## Key Features
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Handling Class Imbalance
- Machine Learning Pipeline (Logistic Regression)
- Model Evaluation
- Streamlit Web Application

## Dataset
Source: Kaggle – Mobile Money Fraud Detection Dataset  
Target variable: `isFraud`

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Seaborn, Matplotlib
- Streamlit

## How to Run
pip install -r requirements.txt
streamlit run app/fraud_detection_app.py
